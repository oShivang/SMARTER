# `sal/search/beam_search_smart.py` — SMART Beam Search with PRM-Based LLM Intervention

## What Is This File?

This file implements **SMART Beam Search with PRM scoring** — an extension of iterative beam search where a Large Language Model (LLM) is invoked to regenerate a step when the PRM score of that step falls below `config.threshold`. The SLM drives the bulk of generation; the LLM is a surgical corrector.

---

## Input Format

### `smart_beam_search(examples, config, slm, prm, llm)`
| Argument | Type | Description |
|---|---|---|
| `examples` | `dict` | Dataset batch with `"problem"` → `list[str]` |
| `config` | `Config` | Config with `threshold`, `n`, `beam_width`, etc. |
| `slm` | `vllm.LLM` | Small Language Model (primary generator) |
| `prm` | `PRM` | Process Reward Model for step quality assessment |
| `llm` | `AutoModelForCausalLM` | Large Language Model (correction oracle) |

---

## Output Format

```python
{
  "completions": [["sol1", "sol2", ...], ...],
  "pred": ["best_solution_per_problem", ...],
}
```

Additionally, each completed `Beam` object carries rich SMART metadata:
- `smart_step`: list of iteration indices where LLM was invoked
- `prm_update`: list of `(old_PRM_score, new_PRM_score)` tuples after each correction
- `gen_update`: list of `(slm_text, llm_text)` pairs showing what changed
- `llm_tokens`: number of tokens generated by LLM per intervention

---

## What It Does

Extends `beam_search.py` with a SMART intervention step injected inside each iteration loop:

After the SLM generates a step and the PRM scores it, any beam whose PRM aggregate score is below `config.threshold` is flagged for LLM correction. The LLM regenerates the **previous step** (from before the SLM's current step was added) for those beams only.

---

## How It Does It (In Detail)

### Setup
Identical to `beam_search.py` — `N` Beams are initialized per problem. Additionally, SMART-specific fields (`smart_step`, `prm_update`, `gen_update`, `llm_tokens`) are initialized per beam.

### Main Iteration Loop

Steps 1–4 are identical to `beam_search.py` (beam management, conversation building, SLM generation, PRM scoring + pruning).

The critical addition:

#### 5. SMART Intervention Check
After pruning, among the surviving (top) beams, those with aggregate PRM score < `config.threshold` are identified as `re_indices`:
```python
re_indices = [top_idx for top_idx in top_indices
              if agg_scores[top_idx][0] < config.threshold]
```

#### 6. LLM Re-generation
For each beam in `re_indices`:
1. The beam is **reverted** to `prev_active_beams[idx]` — the beam state *before* the SLM added its current step.
2. A conversation is built using the reverted beam's `current_text` (i.e., without the last SLM step).
3. `generate_k_steps_for_llm()` is called to have the LLM generate a replacement step using `StopStringCriteria` on `\n\n`.

#### 7. PRM Re-scoring
The LLM-generated step is appended to the reverted beam. `prm.score()` is called again to measure the new score. Both old and new scores are logged in `prm_update`.

#### 8. Metadata Logging
For each corrected beam:
```python
beam.smart_step.append(iterate_idx)
beam.gen_update.append((slm_step, llm_step))
beam.prm_update.append((old_score, new_score))
beam.llm_tokens.append(token_count)
```
The corrected beam replaces its position in `active_beams`.

### Post-Processing
Identical to `beam_search.py`. Additionally, beams that were never corrected have their SMART fields set to `[-1]` sentinel values for downstream analysis.

---

## Key Design Notes

- `prev_active_beams = copy.deepcopy(active_beams)` is saved **before** the SLM step is applied, enabling clean reversal for LLM intervention.
- The LLM here uses HuggingFace's `model.generate()` with `StopStringCriteria` because vLLM lacks native mid-sequence stop-string criteria at the granularity needed.
- The intervention is **per-step, per-beam**: each beam independently decides whether it needs LLM help at every iteration.
- A `smart_done` flag tracks whether any intervention occurred. If not, sentinel values (`-1`) are written to all SMART fields.
